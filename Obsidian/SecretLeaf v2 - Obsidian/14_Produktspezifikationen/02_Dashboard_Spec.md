# Dashboard Spezifikation

## Zweck

Dieses Dokument definiert die funktionalen Anforderungen des SecretLeaf Dashboards.

## Produktziel

Das Dashboard ist die wichtigste Seite für aktive Grower.

Ein Nutzer soll innerhalb von 5 Sekunden verstehen:

- Wie geht es meinen Pflanzen?
    
- Was muss ich tun?
    
- Gibt es Risiken?
    
- Wie entwickelt sich mein Grow?
    

## Erfolgskriterium

Nutzer öffnen das Dashboard regelmäßig während eines aktiven Grows.

## Dashboard Aufbau

### Header

Anzeigen:

- Grow Name
    
- Sorte
    
- Alter
    
- Phase
    

---

### Status Karte

Anzeigen:

- Aktuelle Phase
    
- Tage seit Start
    
- Letzte Aktivität
    

---

### Aufgaben Karte

Anzeigen:

- Fällige Aufgaben
    
- Erinnerungen
    
- Empfehlungen
    

Beispiele:

- Bild hochladen
    
- Gießen
    
- Düngen
    

---

### Risiken Karte

Anzeigen:

- Warnungen
    
- Diagnosen
    
- Auffälligkeiten
    

---

### Fortschritt Karte

Anzeigen:

- Bilder Timeline
    
- Wachstumsverlauf
    
- Historie
    

---

### KI Empfehlungen

Anzeigen:

- Priorisierte Empfehlungen
    
- Optimierungsvorschläge
