# User Flows

## Zweck

Dieses Dokument definiert die wichtigsten Nutzerabläufe innerhalb des SecretLeaf MVP.

Jeder User Flow beschreibt den kürzesten Weg vom Problem zur Lösung.

## Grundprinzip

Jeder Flow soll:

- einfach sein
    
- schnell sein
    
- Daten erzeugen
    
- Nutzerwert schaffen
    

---

# MVP Aha-Moment

Der Nutzer denkt:

"SecretLeaf hilft mir konkret bei meinem Grow."

Nicht:

"SecretLeaf hat viele Funktionen."

## Tier B

Benachrichtigungen

Benchmarks

Prognosen

---

# Erfolgskriterium

Ein neuer Nutzer soll innerhalb von 5 Minuten:

- einen Grow erstellt haben
    
- ein Bild hochgeladen haben
    
- eine Diagnose erhalten haben
    

Dann wurde der wichtigste Teil des MVP erfolgreich abgeschlossen.
