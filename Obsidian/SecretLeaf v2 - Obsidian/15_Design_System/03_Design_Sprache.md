# Design Sprache

## Zweck

Dieses Dokument definiert die langfristige Designsprache von SecretLeaf.

## Inspirationsquellen

Nicht:

- Reddit
    
- Foren
    
- Facebook Gruppen
    

Sondern:

- Linear
    
- Notion
    
- Stripe
    
- Vercel
    
- GitHub
    

## Wahrnehmung

SecretLeaf soll wirken wie:

- modern
    
- intelligent
    
- datengetrieben
    
- professionell
    

## Markenwahrnehmung

Nicht:

Cannabis Lifestyle

Sondern:

Cannabis Intelligence

## Langfristiges Ziel

SecretLeaf soll sich wie ein Cannabis Operating System anfühlen.
